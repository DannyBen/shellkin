NAME
==================================================

**shellkin validate** - Validate feature files and step definition files

SYNOPSIS
==================================================

**shellkin validate** [TARGET]

DESCRIPTION
==================================================

Validate feature files and step definition files

- Alias: **v**

ARGUMENTS
==================================================

TARGET
--------------------------------------------------

- Default Value: **$SHELLKIN_FEATURES_ROOT**
