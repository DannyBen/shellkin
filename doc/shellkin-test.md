**shellkin test** - Run feature tests

SYNOPSIS
==================================================

DESCRIPTION
==================================================

Run feature tests

- *Default Command*
- Alias: **t**

ARGUMENTS
==================================================

TARGET
--------------------------------------------------

- Default Value: **features**
