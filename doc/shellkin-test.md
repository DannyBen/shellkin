NAME
==================================================

**shellkin test** - Run feature tests

SYNOPSIS
==================================================

shellkin [test] [TARGET] [OPTIONS]

DESCRIPTION
==================================================

Run feature tests

- *Default Command*
- Alias: **t**

ARGUMENTS
==================================================

TARGET
--------------------------------------------------

Path to features directory or a single feature file

- Default Value: **$SHELLKIN_FEATURES_ROOT**

OPTIONS
==================================================

--fail-fast, -f
--------------------------------------------------

Abort after the first failing scenario
